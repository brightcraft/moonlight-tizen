# Security Policy

## Supported Versions

Security vulnerabilities may be reported for any publicly released version. Reports will be evaluated based on the affected version, severity, reproducibility, and the current maintenance status of the project.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through [GitHub's private vulnerability reporting](https://github.com/brightcraft/moonlight-tizen/security/advisories/new).

Please do not disclose the vulnerability publicly before it has been investigated and addressed.

When reporting a vulnerability, please include as much of the following information as possible:

* A clear description of the vulnerability and affected functionality
* The affected version and relevant environment details
* Steps to reproduce the issue
* The expected and actual behavior
* Any access or conditions required to reproduce the issue
* The potential security impact and affected resources
* A proof of concept or minimal reproduction, if available
* Relevant logs, screenshots, videos, or other supporting evidence

Reports will be reviewed and investigated as time allows. If the vulnerability is confirmed, a fix will be developed and included in a future release where appropriate.

## Disclosure

Security advisories may be published after a fix is available and the necessary advisory information has been finalized.

Contributors who report or help resolve a security vulnerability may be credited in the corresponding security advisory.
